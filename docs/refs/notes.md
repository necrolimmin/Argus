# Референсы для редизайна Argus

Все скриншоты сняты при ширине окна 1440px.

- `mood-01-verkada.png` (verkada.com/command, блок «Investigate»). Берём общий характер системы безопасности: спокойная подача, сетка камер с подписями поверх кадра, поиск по событиям над сеткой, узкая колонка иконок слева.
- `mood-02-linear.png` (linear.app, продукт ниже первого экрана). Берём тёмный интерфейс без свечений, плотный сайдбар с группами («Workspace», «Favorites») и ясную иерархию: заголовок, описание, лента активности.
- `mood-03-grafana.png` (play.grafana.org, «Grafana Bank — Executive Overview»). Берём ощущение пульта: плотные данные, панели встык, строка управления сверху (период, обновление, частота).
- `screen-events-frigate.png` (frigate.video, экран просмотра событий). Берём ленту распознаваний: превью кадра, «25m ago» и точное время, значок типа события, вкладки «Alerts · 81 / Detections · 242» со счётчиками, фильтр «All Cameras».
- `screen-table-vercel.png` (vercel.com/geist/table, дизайн-система Geist, тёмная тема). Берём тёмные таблицы: тонкие разделители, серые заголовки колонок, числа по правому краю.
- `screen-cameras-dribbble-1.png` («Security Control Panel Design Concept», Conceptzilla, 299 лайков). Берём сетку камер, сгруппированную по зонам («Basement», «Backyard»), вкладки зон сверху и ленту событий справа.
- `screen-cameras-dribbble-2.png` («Home Security Web App for Security Cameras Control», Conceptzilla, 306 лайков). Берём экран одной камеры: крупный плеер, под ним шкала времени с превью событий, лента справа.
- `screen-devices-dribbble.png` («Device Management Dashboard UI», Nixtio, 604 тыс. просмотров). Берём список устройств с владельцем и статусом, карту расположения и блок общего состояния безопасности.

## Не брать

- Неоновые свечения.
- Градиенты.
- Glassmorphism (стекло, размытие фона).
