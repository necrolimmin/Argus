# Argus — дизайн-система

Основано на аудите (`docs/AUDIT.md`) и референсах (`docs/refs/notes.md`). Превью системы:
`docs/design-preview.html`.

Приоритет устройств: **десктоп 1440+** — пост оператора, под него проектируем. 390px должен работать,
но дизайн под телефон не подстраиваем. На телефоне стена камер идёт первой.

---

## 1. Характер

**Пульт оператора поста охраны.** Спокойно, плотно, точно, читается за секунду. Оператор смотрит
на экран часами и должен с одного взгляда понять: что с камерами, кто прошёл, есть ли проблема.

- Видео — главное на экране. Всё остальное приглушено, чтобы не спорить с кадром.
- Цвет несёт смысл: если что-то цветное, значит, это состояние, которое нужно заметить.
- Плотность как у Linear и Grafana: много строк на экране, без воздуха ради воздуха.
- Числа (IP, время, ID) набраны моноширинным и стоят в колонку.

**Анти-характер:** не крипто-стартап (неон, свечения, градиенты), не киберпанк (сканлайны, «HUD»),
не пастельный HR-софт (мягкие карточки, иллюстрации, эмодзи), не стекло.

## 2. Типографика

Сравнение на строках «Сотрудники и учреждения», «Xodimlar va muassasalar», «Oʻzbekiston, gʻalaba»,
«Ўзбекистон, Қўқон, ғалаба, ҳодиса», «192.168.3.110 · 11:21:44 · AF3130537»:

| Шрифт | ʻ (U+02BB) | ў қ ғ ҳ | Табличные цифры | Итог |
|---|---|---|---|---|
| Golos Text | нет (подставляется из запасного шрифта) | есть | есть | нет: чужой знак в каждом «oʻ», «gʻ»; ассоциация с госпорталами |
| IBM Plex Sans | есть, но очень широкий: «O ʻ zbekiston» | есть | только моноширинные | нет: узбекская латиница разваливается |
| **Onest** | есть, ровный | есть | есть (`tnum`) | **берём** |
| Manrope | нет | нет қ ғ ҳ | — | нет |
| **IBM Plex Mono** | есть | есть | — | **берём для цифр** |
| JetBrains Mono | нет | нет қ ғ ҳ | — | нет |

**Шрифты:** `Onest` (400, 500, 600) — весь интерфейс. `IBM Plex Mono` (400, 500) — IP, время, ID камер
и устройств, табельные номера, номера каналов, MAC, серийные номера, порты, счётчики в дереве.
Подключаются через `@fontsource`, без сети.

**Шкала** (одна на всё приложение, других размеров нет):

| Токен | Размер / строка | Где |
|---|---|---|
| `--fs-xs` | 12 / 16 | мета, подписи под именем, заголовки колонок, бейджи |
| `--fs-sm` | 13 / 18 | ячейки таблиц, элементы списков, дерево, лента событий |
| `--fs-md` | 14 / 20 | основной текст, кнопки, поля, пункты меню |
| `--fs-lg` | 16 / 22 | заголовки панелей и модалок |
| `--fs-xl` | 20 / 26 | заголовок страницы (h1) |
| `--fs-2xl` | 24 / 30 | только экран входа |

Насыщенность: 400 текст, 500 имена и кнопки, 600 заголовки. Без 700.
Регистр: всегда предложения. Капс и разрядка запрещены. Отрицательная разрядка только у 20 и 24
(-0.01em).

### Янтарь в светлой теме: варианты

| Б | `#e8a33d` | `#1a1206`, 8.6:1 | 2.0:1 | текст проходит, контур нет; даже `#d98e1c` даёт 2.7:1 |

Вариант Б ярче и ближе к знаку, но кнопка на светлом фоне читается только по тексту. Переключение —
одна строка в токенах (`--accent`, `--accent-hover`, `--accent-ink`).

### Янтарь

Только **главная кнопка** экрана и **активный пункт меню**. Больше нигде: чекбоксы, выбранные
сегменты, выбранный узел дерева, фокус, цель перетаскивания — нейтральные (`--text`, `--surface-3`).
Фокус клавиатуры: кольцо 2px цвета `--text` с отступом 2px.

### Три отдельные системы смысла

Красный (`--danger`) — только настоящие проблемы: устройство не в сети, камера без сигнала, ошибка
загрузки, удаление.

**1. Состояние устройства или камеры — цветная точка 8px + слово.**

| Состояние | Тёмная | Светлая |
|---|---|---|
| В сети (`--state-online`) | `#4fae7c` | `#2f8558` |
| Не в сети (`--state-offline` = `--danger`) | `#e0605a` | `#c0392b` |
| Не проверено (`--state-unknown`) | `#8f9199` | `#8a8d96` |
| Ошибка — точка не используется | красная иконка `TriangleAlert` + текст ошибки | |

**2. Направление — иконка + нейтральный цвет `--text-2`, без красного и зелёного.**
Вход: `ArrowDownToLine` + «Вход». Выход: `ArrowUpFromLine` + «Выход». Без направления — ничего.

**3. Распознавание — форма карточки события, не цвет.**
Опознан: фото сотрудника, имя, должность. Не опознан: кадр 16:9, без имени; колонка подписана
«Неопознанные», поэтому «Не опознан» в каждой строке не повторяется. Цвет у обоих нейтральный.

## 4. Пространство и плотность

Шаг 4px. Токены: `--sp-1` 4, `--sp-2` 8, `--sp-3` 12, `--sp-4` 16, `--sp-5` 24, `--sp-6` 32.
Других отступов нет.

| Что | Значение |
|---|---|
| Сайдбар | 236px (216 мало для «Сотрудники и учреждения» в Onest 14px), свёрнутый 56px, прижат к краю, без отступа от окна |
| Поля страницы | 24px (десктоп), 16px (телефон и 768px) |
| Зазор между панелями | 16px |
| Внутренний отступ панели | 16px |
| Колонка «Структура / Камеры» | 248px; секция «Структура» по высоте содержимого, не больше 40% |
| Строка таблицы (компактная, по умолчанию) | 36px, ячейка 0 12px |
| Заголовок таблицы | 32px, `--fs-xs`, `--text-3`, без фона и без линии сверху |
| Строка дерева / списка камер | 28px / 40px (имя + подпись) |
| Высота контролов | 32px (по умолчанию), 28px (малые, в таблицах и шапках панелей) |
| Стена камер, зазор | 4px |

Таблица растёт на всю ширину, но узкие таблицы (до 5 колонок) не растягивают колонки: последняя
колонка забирает остаток.

## 5. Форма

Меньше рамок: уровни отличаются фоном и отступом. Скругление растёт с уровнем:

| Токен | Значение | Где |
|---|---|---|
| `--r-xs` | 3px | бейджи, чекбоксы, мини-превью в дереве |
| `--r-sm` | 6px | кнопки, поля, сегменты, строки меню, плитки событий |
| `--r-md` | 8px | панели, тайлы камер, таблицы |
| `--r-lg` | 12px | модалки, всплывающие меню |
| — | 50% | только аватар и точка состояния |

Рамка (`--border`) есть только у полей ввода, разделителей строк таблицы и у плавающих слоёв
(модалка, меню). У панелей и тайлов рамок нет. Тень (`--shadow-float`: `0 8px 24px rgba(0,0,0,.4)`,
в светлой `0 8px 24px rgba(20,22,28,.12)`) — только модалка, меню, тост, «призрак» перетаскивания.

## 6. Компоненты

### Сайдбар
Сплошной `--surface-1`, прижат к левому краю, справа без рамки (фон отличается от `--bg`).
Сверху знак и «Argus». Пункты 36px, иконка 18px `--text-2`, текст `--fs-md`.
**Активный:** фон `--surface-3`, текст `--text`, иконка `--accent`, слева полоса 2px `--accent`.
Подложка активного пункта одна и скользит к новому пункту за 200ms (исключение в Motion).
Низ: одна строка 32px — язык (кнопка «文A RU», открывает меню из 4 языков с самоназваниями:
Русский, English, Ўзбекча, Oʻzbekcha; выбранный отмечен галочкой), тема, пользователь, свернуть.
Меню открывается вверх (в верхней панели телефона — вниз), закрывается кликом мимо и Escape.
Кнопки, которые не отправляют форму, всегда `type="button"` (на входе они внутри формы).

### Шапка страницы
h1 `--fs-xl` слева. Справа действия по весу: одна главная (янтарь), одна вторичная, остальные —
ghost. На Устройствах: «Добавить» — главная, «Сканировать сеть» — вторичная, «Импорт из Excel» и
«Учётные данные» — ghost.
Камеры: «Камеры» (h1), под ним путь подразделения `--fs-sm` `--text-2` («Компания / Филиал»),
справа счётчик «4 из 9» моноширинным и переключатель сетки.

### Таблица
Сплошная панель `--surface-1`, `--r-md`. Строки 36px, разделитель 1px `--border`, без зебры.
Наведение — `--surface-2`. Выбранная/раскрытая строка — `--surface-2`, вложенные строки с отступом
32px и `--fs-xs`. Числа и адреса — `--font-mono`, IP и время по левому краю (их сравнивают как
текст), счётчики — по правому. Действия строки — иконки 16px `--text-3`, видны всегда.
Под таблицей пустоты нет: таблица заканчивается последней строкой, под ней строка «6 устройств».

### Таблица устройств (найдено на этапе 6)
- Колонки фиксированной ширины (`table-layout: fixed` и `<colgroup>`): фильтр и раскрытие строки
  их не сдвигают. Длинное значение обрезается многоточием.
- Подразделение — последний узел («necro»), полный путь во всплывающей подсказке.
- Модель и IP — моноширинным; производитель перед моделью — обычным шрифтом.
- Действия строки видны всегда (`--text-3`, ярче при наведении): на сенсорном экране наведения нет.
- Под таблицей строка-итог: «6 из 6 устройств», «Не в сети: 1», «Сбросить фильтры» при фильтре.
- Неудачное обновление не убирает таблицу: последняя удачная версия остаётся, над ней ErrorState
  с временем последнего ответа. ErrorState вместо таблицы — только если данных не было ни разу.
- На телефоне остаются название, IP, статус и действия; тип, модель и подразделение — в карточке.

### Таблица сотрудников (найдено на этапе 6)
- Фото и ФИО в одной ячейке; ФИО и должность обрезаются многоточием, полностью — в подсказке.
- Табельный номер моноширинным, по правому краю.
- Уволенные: текст `--text-2`, вес 400, фото 60% — тише, но читаются.
- Итог под таблицей «N из M сотрудников», «Показать ещё», «Сбросить фильтры».
- На телефоне: ФИО, номер, статус. В фиксированной таблице скрытые колонки не убираются из строки
  (`display: none` сдвинет ячейки), а сжимаются до нуля с `visibility: hidden`.

### Действия строки на телефоне — RowActions
На десктопе иконки в строке; на телефоне одна кнопка «⋯» с меню. Меню позиционируется от экрана
(`position: fixed`), иначе его обрежет прокручиваемая таблица.

### Нет снимка — NoImage / Thumb
Где фото может не быть или оно не загрузилось (снимок устройства, лента событий, фото сотрудника):
нейтральный блок `--surface-2` с иконкой и «Нет снимка» (в маленьких слотах — только иконка,
текст в подсказке). Никогда не чёрный прямоугольник.

### Дерево структуры
Строки 28px, отступ уровня 16px, линии уровней нет. Счётчик справа моноширинным `--text-3`.
Выбранный узел — `--surface-3`, `--r-sm`. Действия узла — кнопка «⋯» 24px: видна у выбранного узла
всегда, у остальных при наведении и фокусе.

### Тайл камеры (все состояния)
Фон `--video`, `--r-md`, без рамки. Подпись внизу слева: плашка `--scrim` (сплошная), `--r-xs`,
имя `--fs-xs` 500 белым, иконка направления и значок распознавания лиц — белые 70%.

| Состояние | Вид |
|---|---|
| В эфире | видео, подпись |
| Подключение | серый каркас `#151515`, по центру спиннер 16px и «Подключение… 4 с» (секунды моноширинным) |
| Нет сигнала | красная точка в подписи; по центру иконка `VideoOff`, «Нет сигнала с 11:21», кнопка «Повторить» |
| Отключена | `--text-3` «Камера отключена», без кнопки |
| Пустая ячейка | без фона, рамка 1px dashed `--border-strong`, по центру «Перетащите камеру» `--text-3` |
| Цель перетаскивания | рамка 2px `--text` |
| Крупная (featured) | та же подпись, `--fs-sm`; ячейка 16:9, видео заполняет её без чёрных полей |

### Выбор подразделения (Камеры, Сотрудники) — компонент UnitPicker
Один компонент на обеих страницах. Вариант `inline` (колонка Камер) раскрывает дерево на месте;
вариант `popover` (панель фильтров Сотрудников) — одна строка высотой с поле, дерево всплывает
слоем под ней (`--r-lg`, `--shadow-float`), закрывается по клику мимо и Escape. Внизу дерева —
действия уровня структуры («Добавить компанию»); нажатие закрывает дерево перед диалогом.
Пока структура грузится — полосы ListSkeleton.

На Камерах это не отдельная панель, а одна строка над списком камер: подпись «Структура» `--fs-xs` `--text-3`,
под ней путь «Компания / Филиал» `--fs-sm` 500 и стрелка. По нажатию под строкой раскрывается
дерево (не выше 40% экрана); выбор узла закрывает его. Открыто само, только пока узел не выбран.

### Список камер
Строка 40px: чекбокс, имя `--fs-sm`, под ним подпись моноширинным `--fs-xs` `--text-3`:
администратор видит «устройство · IP» (cam-4 · 192.168.3.81) — так различаются одинаковые имена;
оператор видит «подразделение · канал 2». Направление — только иконка, слово в подсказке, чтобы
не отнимать ширину у IP.

### Стена
Каждая ячейка 16:9; сетка занимает ту сторону свободного места, которая кончается первой
(контейнерные единицы `cqw`/`cqh`). До 4 камер включительно — ровная сетка (1, 2×1, 2×2) без
крупной ячейки. С 5 камер появляется крупная ячейка: квадратный блок 2×2 или 3×3, поэтому тоже
16:9; в ней стоит камера, которую оператор туда перетащил (по умолчанию первая).
Потоки не 16:9 (тепловизор, 4:3, вертикальный терминал) не обрезаются (`object-fit: contain`),
поля вокруг них — серый фон тайла `--video-idle`, не чистый чёрный.
«Повторить» на тайле перезапускает поток с нуля.

### Лента событий под стеной
Высота по содержимому, не больше 280px. Пустая колонка («Опознанные», «Неопознанные») сужается
до 35% и отдаёт место непустой.

### Карточка события
**Опознан:** строка 52px: фото 40px (`--r-xs`), имя `--fs-sm` 500, ниже «должность · камера»
`--fs-xs` `--text-2`; справа время моноширинным `--fs-sm` и иконка направления.
**Не опознан:** кадр 16:9 шириной 120px (`--r-xs`), справа время моноширинным, камера,
направление; кнопка «Добавить» ghost 28px с иконкой `UserPlus` (только админ).
Новое событие: фон `--surface-3`, тает за 2 с.

### Фильтры-сегменты
Дорожка `--surface-2`, `--r-sm`, высота 32px. Выбранный — плашка `--segment-on` (светлее
`--surface-3`), текст `--text`, вес 600. Остальные — `--text-2`, вес 500. Без янтаря.
Сегмент статусов: точка состояния перед словом. (Вариант без веса 600 и с плашкой `--surface-3`
показан в превью для сравнения.)

Точка состояния + слово (`--fs-xs`). Нейтральный бейдж: `--surface-3`, `--text-2`, `--r-xs`, 20px.

### Пустые, загрузочные и ошибочные состояния

## 7. Motion

Только два движения и одно согласованное исключение, все короткие:

- **Появление события в ленте:** сдвиг 8px сверху + прозрачность, 160ms, `ease-out`; фон
  `--surface-3` тает за 2 с.
- **Раскрытие строки устройства:** высота и прозрачность, 160ms.
- **Исключение — подложка активного пункта меню:** скользит к новому пункту, `transform`,
  не дольше 200ms, `ease-out`. Утверждено отдельно.

Всё остальное меняется мгновенно: наведение, сегменты, тайлы. Без увеличения видео при наведении.
`prefers-reduced-motion` отключает все три: подложка встаёт на место сразу.

## 8. Запреты

- Стекло, `backdrop-filter`, полупрозрачные панели.
- Свечения: цветные тени, `box-shadow` со светом, «светодиоды».
- Градиенты (исключение — нет; подпись на видео лежит на сплошной плашке).
- Фоновые цветовые пятна.
- Панель внутри панели с рамкой.
- Строки таблиц как отдельные карточки.
- Янтарь вне главной кнопки и активного пункта меню.
- Красный вне настоящих проблем, в том числе для «Выход».
- Капс и разрядка в подписях; эмодзи.
- Размеры шрифта, радиусы и отступы вне шкалы; цвета вне токенов.
- Пропорциональные цифры в IP, времени, ID.
